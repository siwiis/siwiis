## 2025-08-31 - GitHub Profile README Naming & Semantic Structure
**Learning:** Renaming a profile entry file to `README.md` in GitHub profile repositories (`username/username`) is critical for GitHub to render the profile UI. Converting flat bullet lists into semantically structured headings improves screen-reader landmark navigation and overall visual hierarchy.
**Action:** Ensure profile repositories use `README.md` as the main entry point and organize information using proper heading hierarchy and semantic sections.
