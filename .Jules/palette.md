## 2025-05-18 - GitHub Profile Entry Point and Semantic Structure
**Learning:** For profile repositories like `siwiis/siwiis`, naming the entry point `README.md` is essential for GitHub to render the profile README on the user page. In addition, organizing flat list items under semantic headings (`#`, `##`) provides necessary navigation landmarks for screen reader users and improves document hierarchy.
**Action:** Always maintain `README.md` as the root entry point for GitHub profile repos and structure content with clear semantic section headings.
