## 2025-05-18 - GitHub Profile Visibility and Semantic Landmark Navigation
**Learning:** For GitHub profile repositories, content must reside in `README.md` to be rendered on the profile page, and replacing unstructured list items with semantic Markdown headings (`#`, `##`) enables screen readers to navigate section landmarks effectively.
**Action:** Always ensure profile content is in `README.md` and uses hierarchical Markdown headings for structured landmark navigation.
