## 2025-05-14 - Profile Visibility and Emoji Accessibility
**Learning:** For documentation-only profile repositories, renaming the entry point to 'README.md' is essential for GitHub profile visibility. Additionally, wrapping emojis in standard Markdown with <span role="img" aria-label="..."> ensures they are accessible to screen readers.
**Action:** Always verify the entry point filename in profile repos and apply ARIA labels to emojis using the span-wrap pattern.
