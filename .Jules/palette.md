## 2025-06-07 - Emoji Accessibility in Profile READMEs
**Learning:** Emojis in GitHub Profile READMEs are often inaccessible to screen readers. Wrapping them in semantic HTML ensures that all users can understand the visual cues and "delight" intended by the author.
**Action:** Always wrap emojis in `<span role="img" aria-label="description">` when enhancing Markdown files for better accessibility.
