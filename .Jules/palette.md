## 2026-09-17 - Profile README UX & Accessibility
**Learning:** For GitHub profile repositories (e.g. `siwiis/siwiis`), content must reside in `README.md` rather than custom filenames (such as `wiis.md`) for GitHub to render it on the user profile. Furthermore, structuring raw bullet points with semantic headings (`#`, `##`) dramatically improves document accessibility and landmark navigation for screen readers.
**Action:** Always rename custom profile markdown files to `README.md` and organize profile information under structured semantic headings.
