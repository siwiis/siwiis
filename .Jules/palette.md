## 2025-07-04 - Accessible Emojis and Profile Visibility
**Learning:** GitHub profile READMEs must be named `README.md` to be visible on the profile page. Additionally, wrapping emojis in `<span role="img" aria-label="...">...</span>` is the standard pattern for screen-reader accessibility in Markdown files.
**Action:** Always verify the entry point filename for profile repositories and apply accessible wrapping to all informative emojis.
