## 2026-07-02 - Profile Visibility and Emoji Accessibility
**Learning:** GitHub profile READMEs must be named `README.md` to render correctly on the profile page; using other names like `wiis.md` prevents visibility. Additionally, emojis in Markdown should be wrapped in `<span role="img" aria-label="...">` to ensure they are accessible to screen reader users.
**Action:** Always ensure the entry point for a GitHub profile is `README.md` and use accessible patterns for all visual-only content like emojis.
