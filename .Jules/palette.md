## 2025-05-18 - GitHub Profile README Naming and Heading Structure
**Learning:** For profile repositories (`user/user`), GitHub requires the file to be named `README.md` at root for profile rendering. Unstructured bullet lists lack heading landmarks for screen reader navigation; converting them to semantic H1/H2 headings significantly improves accessibility and document landmark structure.
**Action:** Always verify profile entrypoint filenames are `README.md` and wrap unstructured profile sections in proper hierarchical headings (`#`, `##`).
