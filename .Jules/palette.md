## 2026-03-30 - GitHub Profile README Naming & Semantic Heading Structure

**Learning:** GitHub profile repositories require the main file to be named `README.md` to be rendered on the user's profile page. Unstructured markdown lists hinder screen-reader landmark navigation; grouping content under semantic headings (`#`, `##`) dramatically improves accessibility and document scannability.

**Action:** Rename `wiis.md` to `README.md` for profile visibility, and structure unstructured bullet points under clear semantic headers.
