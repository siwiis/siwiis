## 2025-01-24 - GitHub Profile Visibility
**Learning:** GitHub only renders the "special" profile README if the file is named exactly `README.md`. Other names like `wiis.md` or `profile.md` will not trigger the profile display.
**Action:** When auditing profile repositories, prioritize renaming the primary markdown file to `README.md` if it isn't already, as this is the most impactful UX fix for visibility.
