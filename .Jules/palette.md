## 2023-11-23 - Profile README UX and Accessibility Structure
**Learning:** For documentation-only profile repositories (such as GitHub profile READMEs), the Markdown file itself acts as the main user interface. Unstructured lists of introductory facts or generic bullet points lack semantic structure, which impairs screen reader landmark navigation and visual layout comprehension. Organizing the content with explicit semantic headings (e.g., #, ##) and logical groupings drastically improves screen-reader compatibility and overall accessibility without requiring heavy markup. Furthermore, preserving raw emojis rather than wrapping them in HTML markup keeps the source file highly readable and easily editable.
**Action:** When optimizing or improving Markdown profiles, restructure flat bullet points into semantically clear sections using appropriate heading levels, and keep emojis raw to maintain readable and editable source code.
