## 2026-06-28 - Profile README Naming and Heading Semantics
**Learning:** Renaming profile entrypoint files from custom filenames like `wiis.md` to `README.md` is critical for GitHub profile rendering. Structuring plain bulleted lists into semantic markdown headings (`#`, `##`) improves screen reader landmark navigation and accessibility.
**Action:** Always verify profile repository entrypoints are named `README.md` and use structured semantic headings for key profile sections.
