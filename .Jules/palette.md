## 2026-10-27 - Profile README Naming & Document Structure Accessibility
**Learning:** GitHub profile repositories strictly require `README.md` to render on user profiles; arbitrary filenames like `wiis.md` render as standard files rather than profile overviews. Converting unstructured list items into structured Markdown headings (`#`, `##`) dramatically improves document outline navigation for screen readers.
**Action:** Always verify profile entrypoint filenames (`README.md`) and structure Markdown profile content with semantic heading landmarks.
