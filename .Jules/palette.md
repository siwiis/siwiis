## 2025-05-18 - GitHub Profile Readme Visibility and Semantic Structure

**Learning:** GitHub profile repositories require the main profile document to be named `README.md` to be rendered on the user's profile page. Using improper file names (like `wiis.md`) renders the profile invisible. Additionally, organizing profile content into semantic headings enhances document structure and screen-reader landmark navigation.
**Action:** Ensure profile content is located in `README.md` and structured with clear semantic markdown headers for optimal accessibility and rendering.
