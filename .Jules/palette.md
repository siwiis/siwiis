## 2025-05-20 - Profile Repository Visibility and Semantic Structure
**Learning:** For single-file profile repositories, naming the profile file `README.md` (rather than custom names like `wiis.md`) is essential for GitHub profile rendering. Structuring unstructured bullet lists with semantic Markdown headers improves screen-reader landmark navigation and visual content hierarchy.
**Action:** Ensure GitHub profile repositories place content in `README.md` and organize content under clear semantic headers (`#`, `##`).
