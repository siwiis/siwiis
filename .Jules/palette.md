## 2024-08-02 - Profile Entry Point and Landmark Navigation
**Learning:** For GitHub profile repositories, the `README.md` file name is required for GitHub to render the profile overview card. Structuring content under semantic section headings (`#`, `##`) improves screen reader landmark navigation without needing extra HTML elements.
**Action:** Verify entry point file name is `README.md` and use clean markdown section headings for structural landmark hierarchy.
