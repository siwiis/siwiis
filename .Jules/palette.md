## 2025-05-10 - Profile README Naming for Profile Visibility
**Learning:** GitHub profile README repositories (like `siwiis/siwiis`) require the file to be named `README.md` in order to render on the GitHub profile user interface. Files named `wiis.md` or other custom names prevent GitHub from recognizing and displaying the profile content to visitors.
**Action:** Always ensure the profile content file is named `README.md` in profile repositories to ensure proper UI rendering and user experience.
