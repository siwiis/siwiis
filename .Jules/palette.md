## 2025-05-10 - Profile README Naming and Semantic Hierarchy
**Learning:** Renaming profile content files from non-standard names (like `wiis.md`) to `README.md` is critical for GitHub profile visibility. Furthermore, converting unstructured bullet list entries into semantic headings (`#`, `##`) dramatically improves landmark navigation for screen-reader users.
**Action:** Always ensure profile repository entrypoints are named `README.md` and use standard Markdown heading structures instead of flat bulleted lists.
