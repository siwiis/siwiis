## 2025-05-10 - Profile Visibility and Heading Hierarchy
**Learning:** Renaming profile entry points from custom filenames to `README.md` is required for GitHub profile rendering. Adding semantic `h1` and `h2` headings establishes document landmarks that screen readers use for efficient section navigation on profile pages.
**Action:** Always structure profile markdown files with proper heading hierarchy (`#` and `##`) rather than flat bullet lists to support assistive technology landmark navigation.
