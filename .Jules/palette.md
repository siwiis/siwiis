## 2025-01-20 - Profile Emoji Representation & Semantic Structures
**Learning:** Standardizing emoji hex codes and descriptions (such as distinguishing 👋 and 👀) in GitHub profiles improves documentation and ensures precise accessibility references across tools. Wrapping raw emojis in standard Markdown files with HTML span tags degrades source document readability, whereas modern screen readers natively support reading raw emojis correctly. Furthermore, converting simple bullet-point profiles into semantically-structured sections (`#` and `##`) provides significantly better visual hierarchy and enables screen-reader users to navigate the profile via heading landmarks.
**Action:** Always verify exact raw emoji hex codes and descriptions before planning, avoid wrapping them with HTML tags in Markdown files, and prefer semantic header tags for outline-based content.
