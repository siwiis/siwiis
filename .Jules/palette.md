## 2024-07-17 - Accessible Emojis and Profile Naming
**Learning:** For documentation-only profile repositories (like `siwiis/siwiis`), renaming the entry file from `wiis.md` to `README.md` is a critical UX improvement for visibility on GitHub. Furthermore, standard emojis should be wrapped with `<span role="img" aria-label="[description]">` to meet strict accessibility standards.
**Action:** When working on profile READMEs, rename the main entrypoint to `README.md` and wrap all emojis in standard HTML accessibility wrappers while maintaining exact, grounded emoji descriptions.
