## 2025-05-18 - Profile README Naming and Landmark Navigation
**Learning:** In GitHub profile repositories (`username/username`), the main profile file must be named `README.md` for GitHub to render it on the user's profile page. Unstructured bullet lists lack semantic heading landmarks for screen readers; grouping items under `<h1>` and `<h2>` headings improves assistive technology navigation.
**Action:** Always verify that profile repositories use `README.md` and organize content with standard Markdown heading landmarks.
