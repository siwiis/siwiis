## 2025-05-18 - Profile Repository Entry Point Naming
**Learning:** For special GitHub profile repositories (`<username>/<username>`), GitHub requires the profile content file to be named `README.md` to properly render on the profile page. Having it named otherwise (e.g., `wiis.md`) prevents it from rendering on GitHub's profile UI.
**Action:** Always ensure the entry point file in profile repositories is named `README.md`.
