## 2025-05-18 - Profile README Naming & Semantic Heading Accessibility
**Learning:** GitHub profile READMEs require exact `README.md` file naming in the user's profile repository to render on profile pages. Additionally, converting unstructured markdown list items into semantic sections with `#` and `##` headings provides landmark navigation for screen readers and improves visual scanability.
**Action:** In documentation-only profile repos, ensure the main file is named `README.md` and use proper markdown heading hierarchy for sections.
