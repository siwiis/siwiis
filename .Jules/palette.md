# Palette Journal

## 2023-11-20 - Markdown List to Heading Semantics
**Learning:** In documentation-only profile repositories (where the README.md itself is the user interface), unstructured lists or bullet points fail to provide screen-reader landmarks. Converting them into semantic markdown headings (`#`, `##`) improves both landmark-based navigation for screen readers and cognitive accessibility for visual learners.
**Action:** Use semantic headings to structure GitHub profiles and user-facing markdown pages to maximize accessibility.
