## 2025-01-20 - Semantic Headings in Profile Readmes
**Learning:** For documentation-only profile repositories where the README serves as the primary user interface, converting a flat list format into semantic headings (H1/H2) significantly improves screen-reader accessibility, landmark navigation, and visual parsing.
**Action:** Always restructure unsemantic flat lists of profile items into hierarchical sections with clear headings when designing or optimizing developer profiles.
