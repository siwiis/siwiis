## 2025-05-14 - Accessible Emojis and Profile Visibility
**Learning:** Wrapping emojis in `<span role="img" aria-label="...">...</span>` in Markdown files ensures that screen readers provide a meaningful description of the emojis. Additionally, GitHub profile repositories require the file to be named `README.md` for it to be rendered on the profile page.
**Action:** Always check for accessible emoji patterns in documentation and ensure the primary entry point is correctly named for its platform (e.g., `README.md` for GitHub profiles).
