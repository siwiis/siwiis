## 2025-05-20 - Profile Repository Entry Point and Accessibility
**Learning:** In GitHub profile repositories (`<username>/<username>`), the entry point must be `README.md` for GitHub to display profile content. Converting flat list items into semantic sections improves document navigation for assistive technologies without adding noise or unnecessary HTML tags.
**Action:** Ensure profile entry point is named `README.md` and use standard Markdown heading structures for clear screen-reader landmarks.
