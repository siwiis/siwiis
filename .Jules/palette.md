## 2023-10-27 - Semantic Landmarks in Markdown Profiles
**Learning:** In documentation-only profile repositories (where the README.md is the main user interface), converting unstructured list entries into proper markdown headers (H1, H2) establishes screen-reader landmarks. This significantly improves accessibility, cognitive parsing, and keyboard/screen-reader navigation.
**Action:** Always structure key profile items as proper headings rather than nested list elements for cleaner visual structure and robust keyboard/landmark accessibility.
