## 2025-01-24 - Profile README Visibility and Renaming Check
**Learning:** In Github profile repositories, naming the profile markdown file as 'README.md' is a critical entrypoint requirement. Having it named anything else (e.g., 'wiis.md') prevents GitHub from recognizing or rendering the profile content on the user's main GitHub profile page.
**Action:** Always verify that profile-only repositories have their main file named exactly 'README.md' to ensure correct UX rendering and profile visibility.
