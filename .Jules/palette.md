## 2025-05-18 - GitHub Profile Readme Accessibility and Landmark Structure
**Learning:** GitHub profile repositories require README.md to render profile content. Structuring bulleted profile text into semantic Markdown headings (# and ##) improves screen-reader landmark navigation and visual readability without requiring HTML span wrappers around emojis.
**Action:** Always ensure profile repos use README.md as the entry point and structure content with semantic headings while preserving raw emojis.
