## 2025-05-15 - Standardizing Accessible Emojis in Profile README
**Learning:** Emojis in GitHub profiles are often not accessible to screen readers. Wrapping them in `<span role="img" aria-label="...">` is a critical micro-UX improvement for accessibility.
**Action:** Always wrap emojis in profile Markdown files with appropriate ARIA labels to ensure a smooth experience for all users. Standard labels used: 👋 (Waving hand), 👀 (Eyes), 🌱 (Seedling), 💞️ (Revolving hearts), 📫 (Mailbox), 😄 (Grinning face with smiling eyes), ⚡ (High voltage).
