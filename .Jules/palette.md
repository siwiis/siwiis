## 2026-07-08 - Profile Visibility and Accessibility
**Learning:** GitHub profile repositories require the entry point to be named `README.md` to render correctly on the profile page. Additionally, emojis in these profiles should be wrapped in ARIA-labeled spans for screen reader accessibility, but should be avoided in Markdown comments to reduce noise.
**Action:** Always ensure the profile entry point is `README.md` and apply accessible emoji wrapping to all visible content.
