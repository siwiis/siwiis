## 2025-05-18 - Profile README Visibility and Semantic Heading Structure
**Learning:** GitHub profile cards only render when the markdown entry point is named `README.md`. Using semantic headings (`#`, `##`) instead of unstructured bullet points creates landmark navigation for screen readers. Raw emojis should remain unwrapped in Markdown as modern screen readers parse them natively and HTML tags reduce document readability.
**Action:** Ensure profile content is located in `README.md`, structure content with semantic Markdown headings for landmarks, and avoid wrapping emojis in HTML tags.
