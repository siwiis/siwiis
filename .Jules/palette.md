## 2026-07-27 - GitHub Profile README Entry Point Visibility
**Learning:** GitHub profile repository content is only parsed and rendered dynamically on the user's profile if the entry point file is named exactly 'README.md' in the root directory. Renaming it or using other names like 'wiis.md' results in profile invisibility, breaking the entire user experience of the profile page.
**Action:** Always ensure GitHub profile repositories have 'README.md' as their main entry point file in the root directory to guarantee accessibility and profile visibility.
