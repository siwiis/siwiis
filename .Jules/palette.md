## 2025-05-10 - GitHub Profile README Entry Point Accessibility
**Learning:** GitHub profile README files serve as the user interface for profile repositories and must be named `README.md` to be rendered on GitHub profile pages. Converting unstructured Markdown lists to semantic headings improves landmark navigation for screen readers.
**Action:** Rename entry point files to `README.md` and use semantic Markdown structure (`#`, `##`) in documentation-only profile repositories.
