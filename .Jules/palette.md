# Palette Journal

## 2023-11-20 - Markdown Heading Semantics for Profile Accessibility
**Learning:** Flat, unstructured bullet point lists in profile READMEs lack visual and cognitive hierarchy. Converting them into semantic markdown headings (`#` and `##`) provides logical landmarks that screen readers can easily navigate and dramatically improves readability for all users.
**Action:** When optimizing repository profile READMEs or user profile documents, structure unstructured lists with clean headings instead of relying solely on flat list items.
