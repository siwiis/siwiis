## 2025-05-18 - Profile Entry Point Filename Requirement
**Learning:** For special GitHub profile repositories (e.g. `username/username`), GitHub strictly looks for `README.md` at the root directory to render the profile section. Using alternative filenames like `wiis.md` breaks the visual interface and profile preview functionality.
**Action:** Always verify that profile markdown content is stored in `README.md` in user profile repositories.
