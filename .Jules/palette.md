## 2025-05-18 - GitHub Profile Entrypoint & Heading Hierarchy
**Learning:** GitHub profile README repositories require the main file to be named `README.md` for profile rendering. Converting unstructured markdown list entries into semantically structured sections (`#`, `##`) improves screen-reader landmark navigation and visual accessibility.
**Action:** Always verify profile entrypoint naming (`README.md`) and use semantic heading hierarchies in documentation-first user interfaces.
