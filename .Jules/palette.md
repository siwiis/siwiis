# Palette Journal

## 2023-11-20 - Markdown Structural Accessibility for Profiles
**Learning:** In repositories containing only profile documents (like `siwiis/siwiis`), the markdown file acts as the primary user interface. Using unstructured lists hinders screen-reader users, whereas breaking down information into semantically nested headings (`#` and `##`) provides logical landmarks for navigation and improves visual scanability.
**Action:** Always structure markdown-based profile entries into clear, semantic headings instead of flat bulleted lists to maximize assistive technology compatibility and logical chunking.
