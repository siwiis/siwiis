## 2025-05-15 - GitHub Profile Visibility and Semantic Landmark Navigation
**Learning:** Renaming profile content to `README.md` is essential for profile rendering on GitHub. Structured Markdown headers (`#`, `##`) dramatically improve screen-reader landmark navigation over unstructured lists without needing HTML wrapping tags.
**Action:** Ensure GitHub profile repositories place user details in `README.md` and use standard Markdown heading hierarchy for accessibility.
