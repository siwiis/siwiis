## 2026-06-21 - Improving Profile Visibility and Emoji Accessibility
**Learning:** GitHub profile repositories must have a `README.md` file in the root to render correctly. Emojis in Markdown should be wrapped in `<span role="img" aria-label="...">` to ensure accessibility for screen reader users.
**Action:** Always check that the profile file is named `README.md` and apply ARIA labels to emojis in static Markdown content.
