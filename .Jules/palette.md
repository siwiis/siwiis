## 2024-06-12 - Accessible Emojis in Markdown
**Learning:** Emojis in plain Markdown are often not accessible to screen readers, which may skip them or read them incorrectly.
**Action:** Wrap emojis in `<span role="img" aria-label="description">...</span>` to ensure they are properly announced by assistive technologies.

## 2024-06-12 - Profile README Naming
**Learning:** GitHub profile repositories only render the content on the profile page if the file is named `README.md`.
**Action:** Ensure the primary profile content is in `README.md`, even if the repository name suggests a different convention.
