## 2025-05-18 - GitHub Profile Entrypoint and Accessible Markdown Structure
**Learning:** GitHub profile READMEs require `README.md` at the root to render on the profile page. Using semantic Markdown headings (`#`, `##`) instead of flat bulleted lists creates clear structural landmarks for screen-reader users navigating documentation.
**Action:** Always rename non-standard entrypoints (like `wiis.md`) to `README.md` for profile repositories, and structure content into semantic sections.
