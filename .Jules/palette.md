## 2026-03-31 - Profile README UX and Accessibility
**Learning:** In GitHub profile repositories (`<username>/<username>`), profile content must reside in `README.md` for GitHub to automatically render it on the user profile page. Using semantic section headings (`#`, `##`) instead of unstructured bullet points enhances screen-reader landmark navigation and visual document hierarchy.
**Action:** Always ensure profile content is in `README.md` and structured semantically with standard Markdown headers.
