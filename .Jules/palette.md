## 2023-11-20 - GitHub Profile README Naming Requirement
**Learning:** GitHub relies strictly on the `README.md` filename at the root of a user's special profile repository (e.g., `username/username`) to render as the main landing page of their profile. Custom filenames like `wiis.md` prevent the content from rendering as the GitHub profile header, creating a poor out-of-the-box user experience.
**Action:** Always verify that the GitHub profile repository entry point is named exactly `README.md` to ensure correct rendering.
