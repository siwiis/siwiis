## 2024-05-20 - Profile Repository Renaming & Semantic Structure
**Learning:** In GitHub profile repositories (`username/username`), renaming `wiis.md` (or non-standard file names) to `README.md` is critical for profile rendering. Organizing flat list content with semantic section headers (`#`, `##`) dramatically improves document structure and assistive technology navigation.
**Action:** When working on GitHub profile repositories, ensure the entry point is named `README.md` and use proper Markdown heading semantics instead of unformatted list items.
