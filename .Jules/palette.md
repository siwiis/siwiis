## 2026-08-04 - Screen-Reader Landmarks and Profile Visibility
**Learning:** Standard GitHub profile repositories require 'README.md' to render. Converting unstructured lists into semantically structured headings (e.g., using h1 and h2) dramatically improves screen-reader landmark navigation and cognitive accessibility.
**Action:** Always structure markdown profiles with hierarchical headings rather than lists, and ensure the profile entry point is named 'README.md'.
