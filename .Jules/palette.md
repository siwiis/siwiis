## 2024-10-24 - Profile README UX and Accessibility
**Learning:** For GitHub profile repositories, the file must be named `README.md` (not `wiis.md`) for GitHub to render it on the profile page. Converting unstructured list items into semantic headers improves accessibility navigation for assistive devices.
**Action:** Always ensure the entry file is `README.md` and use standard Markdown headers without extraneous HTML tags around raw emojis.
