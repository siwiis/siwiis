## 2026-09-21 - GitHub Profile README Visibility & Semantic Structure
**Learning:** For GitHub profile repositories (matching username/username), GitHub specifically renders `README.md`. Alternative file names (e.g. `wiis.md`) fail to render as the main profile document. Converting unstructured list entries into semantically structured headings (`#`, `##`) improves screen-reader landmark navigation and heading hierarchy.
**Action:** Ensure entrypoint is named `README.md` in profile repositories and structure document sections using proper Markdown headings.
