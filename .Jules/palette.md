## 2026-03-30 - Profile README UX and Accessible Landmarks
**Learning:** For single-user profile repositories on GitHub, renaming the main profile markdown file to `README.md` enables GitHub's profile README display feature, and replacing flat bulleted lists with structured markdown headings (`#`, `##`) dramatically improves landmark navigation for screen-reader users.
**Action:** When working on GitHub profile repositories, structure content using semantic headers and verify `README.md` is used as the primary entry point.
