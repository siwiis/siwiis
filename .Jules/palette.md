## 2025-05-18 - GitHub Profile Entrypoint Naming and Heading Structure
**Learning:** Renaming profile files from `wiis.md` to `README.md` is critical for GitHub profile visibility, and converting unstructured lists into semantic H1/H2 Markdown headings drastically improves screen reader landmark navigation.
**Action:** Always ensure profile repos use `README.md` as the root entrypoint and organize profile items into structured Markdown heading sections.
