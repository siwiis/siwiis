# Palette's Journal

## 2025-05-14 - Repository Profile README Activation
**Learning:** The repository `siwiis/siwiis` is a special GitHub profile repository, but the profile content was in `wiis.md`, which GitHub does not recognize for rendering the profile.
**Action:** Renaming `wiis.md` to `README.md` to activate the profile display.

## 2025-05-14 - Emoji Accessibility in Markdown
**Learning:** Emojis in Markdown are often not announced correctly by screen readers.
**Action:** Wrapping emojis in `<span role="img" aria-label="...">` ensures that screen reader users receive the intended context.
