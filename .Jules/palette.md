## 2026-10-19 - GitHub Profile README Entry Point and Semantic Headings
**Learning:** For profile repositories (username/username), GitHub requires the file to be named `README.md` to render on the profile page. Using `wiis.md` hides the profile content completely. Converting flat list items into semantic heading landmarks (`#`, `##`) dramatically improves screen reader navigation and visually structures profile content.
**Action:** Rename `wiis.md` to `README.md` and use proper H1/H2 markdown headings for profile sections without wrapping emojis in extra HTML tags.
