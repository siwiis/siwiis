## 2025-02-19 - GitHub Profile README Visibility and Structure
**Learning:** For special GitHub profile repositories (like `siwiis/siwiis`), renaming `wiis.md` to `README.md` is essential for profile card rendering on GitHub. Converting raw bullet lists into semantic Markdown heading landmarks (`#`, `##`) enables screen readers to navigate via heading shortcuts and improves cognitive hierarchy.
**Action:** Ensure profile entry point is named `README.md` and use semantic level 1 (`#`) and level 2 (`##`) headings instead of unstructured list items.
