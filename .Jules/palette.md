## 2025-06-11 - GitHub Profile README Naming
**Learning:** In a special GitHub profile repository (e.g., username/username), the profile content is only rendered if the file is named `README.md`. Using other names like `wiis.md` prevents the content from being displayed to users.
**Action:** Always ensure the profile README is named exactly `README.md` in special repositories to ensure the UX is delivered as intended.
