## 2026-08-20 - Profile Readme Entry Point and Semantic Structure
**Learning:** GitHub profile repositories (`username/username`) strictly require `README.md` at the root directory to render on the profile page. Furthermore, replacing unstructured bullet lists with proper semantic headings (`#` and `##`) improves screen reader landmark navigation and visual hierarchy.
**Action:** Rename non-standard profile files (e.g., `wiis.md`) to `README.md` and structure contents with semantic section headers.
