## 2026-06-15 - GitHub Profile Visibility and Semantic Markdown Navigation
**Learning:** For profile repositories (`user/user`), GitHub requires the file to be named `README.md` at root for profile rendering. Unstructured bullet lists impair accessibility for screen readers; converting bullet lists into semantic Markdown section headings (`#`, `##`) enables screen reader heading navigation and landmark jump functionality.
**Action:** Always ensure profile content resides in `README.md` and uses structured headings (`#`, `##`) with raw emojis rather than flat bullet lists.
