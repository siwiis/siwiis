## 2026-06-30 - Emoji Accessibility in Profile READMEs
**Learning:** Emojis in GitHub profile READMEs are often inaccessible to screen readers. Wrapping them in `<span role="img" aria-label="...">` ensures that assistive technologies can correctly identify and describe the visual content to users.
**Action:** Use the `<span>` wrapper pattern for all emojis in Markdown-based user interfaces to maintain accessibility standards.
