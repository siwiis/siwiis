## 2026-07-08 - Accessibility and Visibility for GitHub Profiles
**Learning:** GitHub profile content must be in a file named `README.md` in a repository named after the username to be displayed on the profile page. For accessibility, emojis in Markdown should be wrapped in `<span role="img" aria-label="...">` tags to provide context for screen readers.
**Action:** Always verify the entry point filename for profile repositories and apply the accessible emoji pattern to improve inclusive UX.
