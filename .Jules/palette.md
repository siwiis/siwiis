## 2025-05-18 - GitHub Profile README File Naming
**Learning:** In GitHub special profile repositories (e.g. `username/username`), the profile landing page UI strictly requires the primary markdown file to be named `README.md`. Naming or saving it as `wiis.md` or any other file name breaks GitHub's automatic profile interface rendering, causing a complete loss of the profile UI for visitors.
**Action:** Always ensure the entry point file for profile repositories is named `README.md` to guarantee visible landing page rendering.
