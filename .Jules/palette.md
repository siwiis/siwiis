## 2025-05-18 - Profile README Accessibility and Visibility
**Learning:** In profile repositories, renaming entry points from custom `.md` filenames to `README.md` is critical for GitHub profile rendering. Structuring bulleted list content into semantic Markdown headings (`#`, `##`) dramatically improves screen reader landmark navigation.
**Action:** Always ensure GitHub profile repositories use `README.md` and use proper semantic heading structure instead of flat list items for profile content.
