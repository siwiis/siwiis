## 2024-10-20 - Semantic Headings in GitHub Profile READMEs

**Learning:** Unstructured Markdown bullet lists in profile repositories reduce screen reader navigation efficiency. Using standard Markdown headings (`#`, `##`) provides semantic landmarks that assistive technologies use to navigate sections efficiently.

**Action:** When working with profile READMEs or documentation files, organize content into logical sections with standard Markdown headings instead of flat bulleted lists.
