## 2024-08-01 - Semantic Layout for Profile READMEs
**Learning:** Profile READMEs function as the primary user interface for documentation-only repositories. Structuring unstructured bullet-points into hierarchical headings (#, ##) and logical sections significantly improves visual clarity, screen-reader navigation landmarks, and cognitive accessibility.
**Action:** When optimizing documentation-only profiles, always structure flat lists into semantically nested sections with headings to enhance keyboard and screen-reader user experiences.
