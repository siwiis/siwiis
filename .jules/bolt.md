## 2025-05-15 - [README Payload Optimization]
**Learning:** Stripping boilerplate HTML comments and multi-byte punctuation characters (like curly apostrophes) from the profile README can significantly reduce payload size (up to 50%) while maintaining visual fidelity. This improves initial load performance for profile visitors.
**Action:** Always check for redundant comments and multi-byte characters in documentation-only profiles to optimize for size.
