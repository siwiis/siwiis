## 2026-06-21 - Optimization of static profile README
**Learning:** Stripping boilerplate HTML comments and multi-byte punctuation characters (like curly apostrophes) from the profile README can significantly reduce payload size (up to 50%) while maintaining visual fidelity (including emojis).
**Action:** Always check for redundant comments and non-ASCII punctuation in static documentation files for profile repositories to minimize payload.
