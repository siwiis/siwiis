## 2024-07-29 - Markdown Profile Payload Optimization
**Learning:** In profile-only repositories lacking executable code, performance wins can be achieved by optimizing payload sizes of key Markdown files. Removing boilerplate HTML comments and multi-byte curly apostrophes achieves a ~50% payload reduction without sacrificing readability.
**Action:** Always identify opportunities to strip redundant boilerplate comments and convert multi-byte characters to standard equivalents to optimize payload delivery for profile visitors.
